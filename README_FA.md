# مجموعه‌ابزار IP با Python

[English guide](README.md)

دو ابزار کوچک بر پایهٔ تمرین‌های قبلی فهرست IP و ربات تلگرام: برنامهٔ خط فرمان برای قالب‌بندی IPهای معتبر و ربات تلگرام برای تشخیص ویژگی‌های IPv4/IPv6 به‌صورت محلی. ربات **موقعیت جغرافیایی** را پیدا نمی‌کند و به سرویس بیرونی درخواست نمی‌فرستد.

## خط فرمان

```bash
python format_ips.py examples/ips.txt --template "https://example.test/host/{ip}"
```

هر سطر فایل باید یک IP باشد. سطر خالی و توضیح‌های `#` رد می‌شوند و برای ورودی نامعتبر شمارهٔ سطر گزارش می‌شود. IPهای نمونه مخصوص مستندات هستند.

## ربات تلگرام

توکن تازه بسازید، `BOT_TOKEN` را در محیط تنظیم و اجرا کنید:

```bash
pip install -r requirements.txt
python bot.py
```

ربات اولیه توکن مستقیم و پاسخ ثابت از سرویس HTTP داشت؛ آن کد و فهرست IPهای اصلی در این نسخه نیستند. این نسخه فقط از `ipaddress` برای تشخیص ویژگی‌ها استفاده می‌کند. مجوز MIT.
